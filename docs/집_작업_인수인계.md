# KOREA 2050 · 집 작업 인수인계

기준일: 2026-10-06. 다음 목표는 **118동 자리의 2050 아파트 한 동을 UE5에서 1인칭으로 걸어 다닐 수 있는 작은 플레이 구간으로 만드는 것**입니다. 현재 브라우저는 외관 검토 시제품이며 Unreal 게임은 아직 없습니다.

## 유지할 사용자 결정

- 실제 구일의 단지 위치·소속·경계, 공공 도로·보도·학교 위치를 기준으로 합니다. 새 동의 크기·배치·외관·지하주차장은 2050 창작 설계로 구분합니다.
- 주공1차→자이1차, 주공2차→자이2차 등 **한 실제 단지→한 미래 단지**를 유지합니다. 아파트·오피스텔 단지를 합치거나 갈라 다른 브랜드를 섞지 않습니다.
- 본게임은 **1인칭 전용**입니다. 3인칭과 R 시점 전환은 만들지 않습니다. 맵별 미션 방식이며 구일이 첫 제작 맵입니다.
- 유료 에셋·도구·플러그인·구독은 사용하지 않습니다. 새 설치에는 별도 승인이 필요합니다.
- 신영상가/114동의 옛 실물 복원 시제품은 폐기된 작업입니다. 옛 `/shinyeong/`와 `exports/guro2050-blockout.*`를 새 작업의 기반으로 사용하지 않습니다.
- 사용자 지시: **저장소 공개 범위를 다시 조회하지 않습니다.** 포함 파일·비밀정보·기존 자료 제한은 별도로 점검합니다.

## 현재까지 완료한 것

1. 원래 755개 지도 요소와 단지 소속을 유지하는 2D 계획도, 15개 주거/오피스텔 구역의 서로 다른 창작 건축 성격.
2. G05 자이2차의 기존 118동 자리: 본체 **62×22m·78.4m·24층** 외관 시안. 창호·쌍 발코니·난간·석재 저층·입구 광장·새 지하 진입 구상.
3. 공동현관: 양쪽 자동 유리문, 상부 레일, 숫자 키패드. 브라우저에서 시연 번호 **2050**만 문을 열고 5초 뒤 닫습니다. 실제 인증·계정·저장·호출 기능은 아닙니다.
4. 1.65m 입구 근접 시점, 원래 윤곽 비교, 지하 구상 보기, 날짜별 그림자 비교. 걷기/점프가 되는 플레이어가 아니라 고정/회전 검토 카메라입니다.
5. 자체 제작 외관과 공통 부품을 **GLB 4개**로 내보내고 재로딩해 메시·삼각형·외곽·재질·법선·UV0 보존을 확인했습니다.

현재 상세 2D/3D에는 공식 지도 파생 자료가 들어 있습니다. **Git에 들어가는 계측 제외 2D 스냅샷과 이 PC의 상세 로컬 버전은 서로 다릅니다.** 작업을 버린 것이 아니라 동기화 수단을 분리한 것입니다.

| 묶음 | 포함 | 사용 조건 |

| `GUIL2050_local-data_2026-10-06.zip` | 상세 계획 JSON/SVG, 3D 시안 JSON, 도로/보도 파생 자료, 계측 근거 파일 | 상세 지도·3D 검토·데이터 의존 테스트 재현에 필요합니다. 사용자 PC 간 로컬 전달용이며 GitHub에 올리지 않습니다. |
| 현재 PC의 Three.js 설치본 | `node_modules/three` 0.180.0 | Git/ZIP에는 포함하지 않습니다. 집 설치 여부는 미확인이고 정식 의존성 등록/새 설치는 아직 승인받지 않았습니다. |

ZIP 위치는 현재 PC의 `C:\seoul_3Dgame\work\home-handoff\`입니다. 원자료 다운로드 ZIP/SHP 전체, `.git`, 비밀번호/토큰, `node_modules`, 옛 구현 백업은 넣지 않습니다. ZIP의 `local-data-manifest.json`에는 파일별 크기와 SHA-256이 있습니다.

## 집에서 받는 순서

작업 기준 폴더는 `C:\seoul_3Dgame`입니다. 다른 PC의 `127.0.0.1`은 집 PC의 서버를 뜻하지 않습니다.

1. 집 기존 폴더의 `git status --short --branch`를 확인하고 수정 파일은 보존합니다. 초기화 이전 옛 이력이면 일반 pull로 합치지 말고 폴더를 보관한 뒤 새로 clone합니다. `1572cd8` 이후의 현재 이력인지 확인하십시오.
2. 같은 현재 이력의 깨끗한 작업 사본이면 다음과 같이 pull합니다. 로컬 수정/상세 지도 덮어씌운 파일이 있으면 먼저 백업하고 충돌을 강제 덮어쓰기로 해결하지 않습니다.

```powershell
cd C:\seoul_3Dgame
git pull --ff-only origin main
```

새 사본이 필요하면 기존 폴더를 삭제하지 않고 빈 경로를 사용합니다.

```powershell
git clone https://github.com/1ritaron8/seoul_3Dgame.git C:\seoul_3Dgame_2050
```

3. UE5 외관 모델만 가져오려면 Git의 `exports/guil2050_118/`만으로 충분합니다. 상세 브라우저 시안도 볼 경우 로컬 ZIP을 사용자 PC 간에 복사합니다.
4. ZIP을 먼저 별도 폴더에 풀어 manifest/경로를 확인한 뒤 `docs/` 내용을 집 프로젝트의 `docs/`에 병합합니다. 동명 사용자 수정 파일은 백업 후 교체합니다. 상세 계획 JSON/SVG 2개가 Git에서 수정 상태로 보이는 것은 의도된 로컬 계측 버전 차이입니다. **이 두 상세 파일과 로컬 자료를 `git add -A`로 올리지 않습니다.**
5. 복원 파일의 해시를 manifest와 비교합니다. 코드 버전/줄바꿈이 바뀌었으면 상세 자료 복원 후 `npm.cmd run build:pilot`으로 3D 생성 기록을 갱신하고 원본 지도·단지 소속 보존을 검사합니다.

## 실행과 검증

현재 PC는 Node.js **24.19.0**, 기존 Three.js **0.180.0**을 사용했습니다. 집 버전은 확인해야 합니다. 이번 인수인계에서 새 프로그램은 설치하지 않았습니다.

```powershell
cd C:\seoul_3Dgame
node --version
npm.cmd start
```

- 기본 2D: `http://127.0.0.1:4173/` — Node.js만 필요합니다. Git 스냅샷에는 NGII 측정 레이어가 없습니다.
- 상세 3D: `http://127.0.0.1:4173/pilot/` — **로컬 자료 복원 + Three.js 기존 설치본**이 모두 필요합니다.
- 공동현관: `입구 근접 · 1.65m` 후 E 또는 `공동현관 키패드 · E` → 2050 입력.
- `npm.cmd ci`가 Three.js를 설치한다고 가정하지 마십시오. 현재 package.json/lock에는 Three.js가 정식 의존성으로 등록되어 있지 않습니다. 집에 없으면 승인 후 설치 경로를 정합니다.

로컬 자료와 기존 Three.js가 있는 Node 24 환경의 전체 검사:

```powershell
node --test --test-isolation=none tests/*.test.mjs
```

직전 전체 결과는 **138개 중 137개 통과, 선택적 proj4 검사 1개 건너뜀, 실패 0개**입니다. Windows에서 일반 테스트 프로세스 분리는 `spawn EPERM`이 있어 위 옵션으로 검증했습니다. GLB 4개 재로딩, 브라우저 오입력 거부·자동 열림/닫힘·E 키·원자료/지하 보기 전환도 확인했습니다. 집 UE5 임포트와 성능의 검증 결과는 아닙니다.

## UE5로 가져갈 파일

모두 `exports/guil2050_118/` 안에 있습니다.

- `guil2050_118_exterior.glb`: 한 동의 외관 전체.
- `module_double_entrance.glb`: 공동현관 문틀/레일/양쪽 문짝/키패드.
- `module_window_bay.glb`: 창호 한 베이.
- `module_balcony_pair.glb`: 쌍 발코니와 난간.
- `manifest.json`: 단위·원점·외곽·부품/삼각형 수·재질·재로딩 결과·파일 해시.

GLB는 **m/Y-up**, UE 길이 기준은 **cm**입니다. 가져오기/단위 변환은 [README](../README.md)에 연결한 공식 안내를 따르고 집 UE5 버전에서 확인합니다. 액터에 추가 100배 스케일을 중복 적용하지 않습니다. 본체 명목값 **6200×2200×7840cm**, 문 한 짝 **148×260cm**로 교차 확인합니다. 외피 돌출을 포함한 모델 외곽은 manifest를 사용합니다. 전체 건물과 별도 부품을 같은 위치에 겹쳐 배치하지 않습니다.

GLB에는 도로/보도·GIS 좌표·이웃 동·부지/주차장·사진/로고가 없습니다. 문짝 그룹은 분리되어 있지만 **브라우저 열림 로직/애니메이션·인증·충돌·실내는 GLB에 포함되지 않습니다.**
