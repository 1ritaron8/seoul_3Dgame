# 집 작업 인수인계 · 구일 2026 UE5

## 현재 결정과 상태

- 배경은 2026년 구일, 분위기는 선택한 2번 미니어처풍입니다. **1인칭·혼자 탐험**을 우선하고 유료 에셋·플러그인·구독은 사용하지 않습니다.
- UE5 프로젝트나 실행 가능한 게임은 아직 없습니다. 집 PC에 UE5가 설치되어 있는지와 그 버전도 아직 확인하지 않았습니다. FHD 120fps 이상은 목표이며 측정 결과가 아닙니다.
- 기존 Three.js 브라우저 시안과 2050년 창작 계획은 Git의 현재 작업에서 제외했습니다. 구일 지도·격자 조사·신영상가 외관 데이터와 변환 자산은 보존했습니다.

## 집 PC에서 저장소 받기

기존 `C:\seoul_3Dgame`이 있다면 PowerShell에서 다음을 실행합니다.

```powershell
cd C:\seoul_3Dgame
git status --short --branch
git pull --ff-only origin main
```

변경된 파일이 표시되면 먼저 그 작업을 보존하고 비교합니다. Git 이력은 유지했으므로 정상 동기화에는 강제 초기화가 필요하지 않습니다. 폴더가 없다면 다음 명령으로 새로 받습니다.

```powershell
git clone https://github.com/1ritaron8/seoul_3Dgame.git C:\seoul_3Dgame
```

## 다음 제작 순서

1. 집 PC에서 UE5의 설치와 버전을 확인하고, 저장소 안의 새 프로젝트 폴더에 First Person Blueprint 프로젝트를 생성합니다.
2. `exports/guil-map-ue5-transfer/guil-map-reference.fbx`와 `exports/shinyeong-ue5-transfer/shinyeong-v13.fbx`를 가져옵니다. 지도선은 배치 참고용으로만 사용합니다.
3. 두 자산의 상대 위치, 축, 캐릭터와 문·건물의 크기, 간판 재질을 실제 UE5 화면에서 확인합니다. Blender는 미터, UE 기본 길이는 센티미터이므로 가져오기 배율을 중복 적용하지 않습니다.
4. 신영상가 주변의 도로·보도와 건물을 UE5에 배치하고, 사진으로 확인한 외관과 미니어처풍을 기준으로 모델·재질을 다듬습니다. 조사 근거는 [지도 기준](구일_지도_기준.md)과 [신영상가 외관 기준](신영상가_외관_기준.md)에 있습니다.
5. 실제 집 PC에서 플레이·충돌·프레임을 측정해 최적화합니다.

## 주의할 구분

신영상가는 Blender에서 형상과 5개 간판 텍스처를 확인한 이전 외관입니다. 외관 일부 치수와 가려진 부분은 추정이고, 일부 간판은 가상입니다. 지도 참고선에는 OpenStreetMap 기반 지형과 2025년 국토지리정보원 수치지도 파생 도로·보도 외곽선이 함께 들어 있습니다. 선의 표시 굵기는 실제 폭이 아니고 UE5에서 맞는 크기와 위치를 확인하기 전입니다. 원본 수치지도와 로드뷰 사진은 저장소에 없습니다.
