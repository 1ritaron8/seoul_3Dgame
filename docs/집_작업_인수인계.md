# 집 작업 인수인계 · 구일 2026 UE5

## 현재 목표와 결과

2026년 구일의 배치를 살린 **미니어처풍 1인칭 탐험**입니다. 유료 에셋·플러그인·구독은 사용하지 않습니다. 이 PC에는 UE5가 확인되지 않아 UE 프로젝트나 실행 게임은 아직 없고, 집 PC의 UE5 설치·버전도 미확인입니다.

여기서는 신영상가 앞 120m × 110m의 도로 구역·보도 초안을 Blender와 FBX로 만들었습니다. 2025년 수치지도 도형에 기반하며 보도 높이·포장과 미확인 지면은 임시 표현입니다. 기존 신영상가 참고 모델과 공통 원점, FBX 축·단위 메타데이터, Blender 재가져오기 형상과 지하 계단 가림 여부를 검사했습니다. UE에서의 결과는 미검증입니다.

## 집 PC에서 받기

```powershell
cd C:\seoul_3Dgame
git status --short --branch
git pull --ff-only origin main
```

변경된 파일이 있다면 덮어쓰지 말고 먼저 확인합니다. 폴더가 없다면 `git clone https://github.com/1ritaron8/seoul_3Dgame.git C:\seoul_3Dgame`으로 받습니다.

## 다음 실행 순서

1. 집 PC에서 UE5 설치·버전을 확인하고, `C:\seoul_3Dgame\Guil2026` 같은 새 폴더에 First Person Blueprint 프로젝트를 만듭니다.
2. [UE5 자산 가져오기 안내](UE5_자산_가져오기.md)대로 거리와 신영상가 FBX를 **새 자산 폴더**로 가져옵니다. 스크립트는 레벨을 만들거나 기존 자산을 바꾸지 않습니다.
3. 거리 메시와 신영상가의 6개 그룹을 같은 위치·회전·배율로 배치한 뒤 실제 UE에서 축과 크기를 확인합니다. 참고 건물의 출입구, 후면과 지하 계단 및 일부 가상 간판도 확인합니다.
4. 도로·보도에 충돌을 설정하고 플레이어 시작점을 보행 가능한 곳에 놓아 이동·점프·출입구 주변을 시험합니다. 충돌 설정은 아직 만들어지지 않았습니다.
5. 미니어처풍 재질과 주변을 다듬은 뒤 집 PC FHD에서 프레임을 측정합니다. **120fps 이상은 목표이지 현재 검증 결과가 아닙니다.**
