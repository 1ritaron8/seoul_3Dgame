# 집 작업 인수인계 · 구일 2026 UE5

## 집에서 바로 걷기

집 PC에 **Windows용 UE5와 해당 버전의 First Person Blueprint 템플릿**이 설치되어 있으면 됩니다. 실행에는 UE5에 포함된 Python을 사용합니다. Blender, 별도 Python, Visual Studio는 필요하지 않습니다.

기존 작업 폴더의 `git status` 첫 줄이 `main`인지 확인합니다. 집에서 편집한 파일이 있으면 내용을 보존한 뒤 받습니다. PowerShell에서 다음을 실행합니다.

```powershell
cd C:\seoul_3Dgame
git status --short --branch
git pull --ff-only origin main
if ($LASTEXITCODE -eq 0) { .\Play-Guil.cmd }
```

처음 받는 PC에서는 `git clone --branch main https://github.com/1ritaron8/seoul_3Dgame.git C:\seoul_3Dgame`을 먼저 실행합니다. 이전 이력이나 로컬 커밋 때문에 `--ff-only`가 중단되면 기존 폴더를 보관하고, 비어 있는 다른 경로에 새로 clone해서 그 안의 [Play-Guil.cmd](../Play-Guil.cmd)를 실행합니다.

첫 실행에는 엔진이 기본 1인칭 팩을 추가하고 거리와 건물을 가져와 `Guil2026/Content/GuilWalk/ShinyeongWalk.umap`을 생성합니다. 처음에는 콘솔에 표시된 로그 경로를 두고 기다리면 됩니다. 생성과 검사가 끝나면 게임 창이 열립니다. 이후에는 같은 실행 파일을 더블클릭하면 저장한 레벨에서 시작합니다.

**WASD**로 걷고 **마우스**로 시선을 돌립니다. 맞은편 보도에서 약국 옆 서측 정문으로 길을 건넙니다. 정문 앞에서 오른쪽으로 돌아 상가를 왼쪽에 두고 지하계단 바깥을 지나면 기계식 주차장 옆 후면 양개문에 도착합니다. 게임 창은 **Alt+F4**로 닫습니다. [29초 동선 미리보기](../exports/guil-street-ue5/walk/shinyeong_walkthrough.mp4)

## 게임 창이 열리지 않을 때

- **UE5를 찾지 못한 경우** 실행 파일은 PATH, Epic Launcher 설치 목록, 기본 설치 폴더 순으로 확인합니다. Launcher나 기본 폴더에 여러 버전이 있으면 가장 높은 5.x 버전을 선택합니다. 직접 지정하려면 다음 예시의 경로를 집 PC 설치 위치로 바꿉니다.

  ```powershell
  .\Play-Guil.cmd -UnrealEditor "D:\Epic Games\UE_5.6\Engine\Binaries\Win64\UnrealEditor.exe"
  ```

- **First Person 팩이 없는 경우** 설치된 UE5의 Epic Games Launcher 옵션에서 **Templates and Feature Packs**를 추가하거나, 에디터의 콘텐츠 브라우저에서 기본 First Person Blueprint 팩을 추가한 뒤 다시 실행합니다. 에디터 메뉴로 생성하고 Play를 누르는 순서도 있습니다. [에디터 수동 실행](UE5_자산_가져오기.md)
- **레벨 생성 중 멈춘 경우** 콘솔에 나온 `Guil2026/Saved/GuilWalk-home-*.log`에서 `GuilWalk failed` 또는 Python 오류를 확인합니다. FBX 가져오기 단계부터는 `Guil2026/Saved/GuilWalk_*.json`에 상세 결과도 남습니다. 같은 프로젝트를 다른 에디터에서 편집 중이면 저장하고 닫은 뒤 실행합니다.

## 이번 작업과 검증 범위
